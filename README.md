# OFFSCRIPT — Responsive Streetwear Website

A front-end website concept for OFFSCRIPT, an all-gender youth streetwear brand. Built with semantic HTML, CSS, and vanilla JavaScript.

## Files
- `index.html` — homepage
- `collection.html` — collection/shop page
- `styles.css` — visual design, layouts, and responsive breakpoints
- `script.js` — mobile navigation, wishlist toggles, demo quick-add, newsletter feedback, filters, and sorting

## Run locally
Open `index.html` in a modern browser. No build tools, dependencies, API keys, or internet connection are required.

## Responsive behaviour
The layout uses CSS Grid and Flexbox with breakpoints for desktop, tablet, and mobile widths. The navigation becomes a collapsible menu on small screens; product grids and filter controls adapt to the viewport.

## Interactivity
- Mobile navigation toggle
- Wishlist button state
- Demo shopping-bag counter and toast feedback
- Front-end newsletter confirmation (does not submit data)
- Collection category, size, and price filters
- Product sorting
- Clear filters and load-more demo action

## Design system
- Warm ivory: `#F5F3EE`
- Burgundy: `#7E303A`
- Charcoal: `#242321`
- Muted stone: `#D9D3C9`

## Important
This is a front-end learning/demo project. It has no backend, real checkout, account system, persistent cart, inventory, or real newsletter service. Product artwork is created with CSS shapes, not product photography.
